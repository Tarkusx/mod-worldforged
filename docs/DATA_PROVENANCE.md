# Data provenance

This project records an independent reconstruction workflow using live SavedVariables observations, AtlasLoot research, structural item-cache parsing, local DBC analysis, WorldMapArea coordinate conversion, terrain/VMAP validation, and manual review.

Raw captures, client archives, DBC/WDB files, databases, and private configuration are intentionally excluded.
